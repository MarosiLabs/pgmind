# structural

Edits that move blocks without touching their text: insertions, deletions, re-wrapping, re-classification. Nothing here should cost identity — position is not identity (Law 4) — so these cases mostly measure whether *ord churn* leaks into the carry.

## case: insert-middle

**why:** everything after the insertion point shifts by one ord. If any of that churns, the engine is treating position as identity.

### before

`````markdown
# Doc

Alpha.

Beta.
`````

### after

`````markdown
# Doc

Alpha.

Inserted.

Beta.
`````

### same

- before[0] => after[0]
- before[1] => after[1]
- before[2] => after[3]

### index

<!-- generated by `make reindex-corpus` — do not hand-edit -->

    before[0] heading        # Doc
    before[1] paragraph      Alpha.
    before[2] paragraph      Beta.

    after[0] heading        # Doc
    after[1] paragraph      Alpha.
    after[2] paragraph      Inserted.
    after[3] paragraph      Beta.

## case: delete-middle

**why:** the mirror image — everything after shifts back by one.

Beta.

### after

Beta.

## case: wrap-in-section

**why:** a heading is added above untouched prose. Content is identical, `heading_path` changes for every block, and the heading itself is new.

### before

`````markdown
Alpha paragraph.

Beta paragraph.
`````

### after

`````markdown
# New heading

Alpha paragraph.

Beta paragraph.
`````

### same

- before[0] => after[1]
- before[1] => after[2]

### index

<!-- generated by `make reindex-corpus` — do not hand-edit -->

    before[0] paragraph      Alpha paragraph.
    before[1] paragraph      Beta paragraph.

    after[0] heading        # New heading
    after[1] paragraph      Alpha paragraph.
    after[2] paragraph      Beta paragraph.

## case: frontmatter-added

**why:** frontmatter is preamble, not a block — but it moves every span in the document. Identity must not notice.

### before

`````markdown
# Doc

Body text that does not change.
`````

### after

`````markdown
---
title: Doc
---

# Doc

Body text that does not change.
`````

### same

- before[0] => after[0]
- before[1] => after[1]

### index

<!-- generated by `make reindex-corpus` — do not hand-edit -->

    before[0] heading        # Doc
    before[1] paragraph      Body text that does not change.

    after[0] heading        # Doc
    after[1] paragraph      Body text that does not change.

## case: paras-to-list

**why:** every block is reclassified at once, text unchanged — and because a list item holds a paragraph, the paragraphs survive under new wrappers rather than changing kind. The two `list_item` blocks are genuinely new; the prose is not.

### before

`````markdown
Alpha item text.

Beta item text.
`````

### after

`````markdown
- Alpha item text.
- Beta item text.
`````

### same

- before[0] => after[1]
- before[1] => after[3]

### index

<!-- generated by `make reindex-corpus` — do not hand-edit -->

    before[0] paragraph      Alpha item text.
    before[1] paragraph      Beta item text.

    after[0] list_item      Alpha item text.
    after[1] paragraph      Alpha item text.
    after[2] list_item      Beta item text.
    after[3] paragraph      Beta item text.

## case: list-flattened

**why:** a nested item is promoted to the top level. The text is untouched and so are the ords; only `parent_block` moves — which is a positional fact, recomputed on every write, so every ID here must survive it.

### before

`````markdown
- parent item
    - child item
`````

### after

`````markdown
- parent item
- child item
`````

### same

- before[0] => after[0]
- before[1] => after[1]
- before[2] => after[2]
- before[3] => after[3]

### index

<!-- generated by `make reindex-corpus` — do not hand-edit -->

    before[1] paragraph      parent item
    before[2] list_item      child item
    before[3] paragraph      child item

    after[0] list_item      parent item
    after[1] paragraph      parent item
    after[2] list_item      child item
    after[3] paragraph      child item
