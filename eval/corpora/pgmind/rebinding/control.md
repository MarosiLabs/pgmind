# control

Cases with a known-deterministic answer. They are here to catch regressions in RFC-004 Part A and to keep the headline number honest: a corpus made only of hard shapes reports a low score that says nothing about whether the easy shapes still work.

## case: identical

**why:** byte-identical input. RFC-003 D6 short-circuits before the carry runs at all, so this must be perfect and free.

### before

`````markdown
# Doc

Alpha paragraph.

Beta paragraph.
`````

### after

`````markdown
# Doc

Alpha paragraph.

Beta paragraph.
`````

### same

- before[0] => after[0]
- before[1] => after[1]
- before[2] => after[2]

## case: blank-lines-added

**why:** whitespace between blocks changes, block text does not. The document's bytes differ, so the short-circuit does not fire and the carry has to do the work.

### before

`````markdown
Beta.
`````

## case: all-marked-rewrite

**why:** the escape hatch, working as intended — every block is rewritten *and* reordered, and identity is still exact because the text asserts it. This is what a sync client that cares about identity is supposed to emit.

### before

`````markdown
# Doc ^h

Alpha paragraph. ^a

Beta paragraph. ^b
`````

### after

`````markdown
# Document ^h

Beta paragraph, rewritten. ^b

Alpha paragraph, rewritten. ^a
`````

### same

- before[0] => after[0]
- before[1] => after[2]
- before[2] => after[1]

### index

    before[1] paragraph      Alpha paragraph.  ^a
    before[2] paragraph      Beta paragraph.  ^b

    after[0] heading        # Document  ^h
    after[1] paragraph      Beta paragraph, rewritten.  ^b
    after[2] paragraph      Alpha paragraph, rewritten.  ^a

## case: marker-collision

**why:** two blocks claim one marker — dirty imports do this. A3 pass 1 resolves by document order: the lowest-ord claimant wins the marked block's ID and the loser falls through.

This case was authored asserting the loser *mints*, which was the deterministic engine's behaviour and not the ground truth: "Beta." → "Beta, edited." is plainly the same block edited, and it carries once rebinding exists. The corpus was encoding a limitation as an answer — exactly what its own README says not to do. What the case is actually for survives the fix: the second claimant must not get the *marked* block's ID.

### before

`````markdown
Alpha. ^dup

Beta.
`````

### after

`````markdown
Alpha, edited. ^dup

Beta, edited. ^dup
`````

### same

- before[0] => after[0]   # the marker's lowest-ord claimant
- before[1] => after[1]   # not the marker's; an ordinary edit in place

    after[0] paragraph      Alpha, edited.  ^dup
